# Klavye Üstünde Uyuyan Kedi Simülatörü

## Bu Ne?

Bu, insanlık tarihinin en önemli yazılım projesidir. Kedilerin klavye üstünde uyurken nasıl "kod yazdığını" simüle eden dünyanın tek ve en gerçekçi programı.

Kediler yazmayı bilmez. Ama bu onları durdurmaz. Bu program da onları durdurmaz.

## Nasıl Çalışır?

1. Programı çalıştır.
2. Kedi uyanır.
3. Rastgele tuşlara basar veya miyavlar.
4. Uyuyakalır.
5. Sen hayatın anlamını sorgularsın.

```bash
python kedi_simulatoru.py
```

## Özellikler

- %100 gerçekçi kedi davranışı
- Hiçbir şey yapmaz ama yapar gibi görünür
- Kedin yoksa bile çalışır
- AI destekli değildir, sadece random

## Neden Bu Proje?

Çünkü birileri "dünyayı kurtaracak kod" yazarken, biz kediyi uyuttuk. Öncelikler.

## Lisans

Bu kodu istediğin gibi kullan. Kediler zaten patent almaz.
